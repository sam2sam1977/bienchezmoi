# Bien chez moi — démo (Habitatpresto)

Application web installable (PWA) : 141 écrans, données d'exemple, aucune demande réelle envoyée.

## Mettre en ligne sur Render
1. Crée un dépôt GitHub (privé) et mets-y tous les fichiers de ce dossier, à la racine.
2. Sur render.com : New → Static Site → choisis le dépôt.
3. Build Command : laisser vide. Publish Directory : `.`
4. Create Static Site. L'URL ressemble à https://bien-chez-moi.onrender.com

(Ou New → Blueprint : Render lit `render.yaml` et configure tout seul.)

## L'installer comme une app sur téléphone
- iPhone (Safari) : Partager → « Sur l'écran d'accueil ».
- Android (Chrome) : menu ⋮ → « Installer l'application ».

## Pour la démo
- `#plan-app` liste tous les écrans.
- Mon compte → « Remettre la démo à zéro » pour repartir des données d'origine.
